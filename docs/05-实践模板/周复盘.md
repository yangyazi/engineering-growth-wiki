# 周复盘

每周一次，用不超过二十分钟填完。目的是判断这一周有没有真的推进，而不是记录自己有多忙。

复制本页作为每周的记录。

## 本周推进的对象

- 项目 / 模块：
- 这一周持续在解决的那个问题：
- 从哪一步开始，停在哪一步：

## 做了什么，产生了什么证据

| 我做的事 | 产出物 | 证据 |
|---|---|---|
| 例：追了一条下单链路的调用 | 调用链笔记 | 代码阅读记录第 3 条 |
|  |  |  |

> 没有产出物的一周也是有效信息：说明任务边界没定清楚，或者一直在换题。

## 哪些判断是我自己做的

- 我提出的假设：
- 我用什么方式验证（运行 / 测试 / 日志 / 对比实现）：
- 结论是事实还是推断：
- AI 帮了什么，哪些地方我没有核对就直接接受了：

## 卡住的地方

- 卡点描述：
- 卡了多久，试过哪些方向：
- 是知识缺口、环境问题，还是问题定义不清：
- 下周准备怎么破（补哪个原理 / 请教谁 / 换更小的切入点）：

## 下周的一件事

只写一件，写得具体到可以开始动手：

- 下周要完成的一件事：
- 完成的标准（能演示 / 能测过 / 能讲清）：

## 本周新增的知识缺口

- 缺口：
- 它出现在哪个工程问题上：
- 什么时候补、补到什么程度够用：
